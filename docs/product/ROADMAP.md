# Product Roadmap

## Now — prove the user journey
**Outcome:** convert the strong runtime platform into a complete product demo.
- Commit one deterministic security trigger.
- Prove Wazuh detection.
- Commit/test Wazuh→Shuffle routing.
- Preserve final response/evidence.

## V1 — observable integration platform
**Outcome:** reduce change risk and diagnosis time.
- Explicit failure-injection scenario.
- Product-doc freshness gate in CI.
- Dependency graph / configuration-drift checks.
- Reusable scenario evidence format.

## V2 — AI-assisted analyst
**Outcome:** reduce analyst effort without surrendering control.
- Curated RAG knowledge layer.
- AI triage / workflow suggestions.
- Evaluation dataset and quality thresholds.
- Human approval for material actions.

## V3 — governed autonomy
**Outcome:** automate selected low-impact actions safely.
- Policy-based action classes.
- Confidence and approval thresholds.
- Rollback and audit evidence.
- Safety and quality metrics.

## Prioritization logic

**Reliability → evidenced user journey → visibility → assistance → governed action.**

The current repository is already strong on reliability. The next highest-value PM move is not another infrastructure feature; it is closing the end-to-end evidence gap.
