# Success Metrics

These are product hypotheses until instrumented and baselined. No invented KPI improvement is presented as fact.

| Metric | Definition | Current state |
|---|---|---|
| Workflow completion rate | % canonical security scenarios reaching expected response/evidence | **Not yet instrumented** |
| Deployment reproducibility | % clean rebuilds passing required health gates | **Mechanism implemented; baseline not stored** |
| Diagnosability | Time from failed validation to identified failing contract | **Mechanism partially implemented; baseline not stored** |
| Analyst effort | Manual steps from alert to defensible decision | **Not yet measured** |
| Documentation freshness | Material changes accompanied by required architecture/product artifact updates | **Architecture gate implemented; product gate pending** |
| CI reliability | Secret/lint/test/docs pipeline success | **Implemented; latest main pipeline passed** |
| AI suggestion quality | Future evaluated suggestion quality | **Roadmap** |
| Unsafe/incorrect AI action rate | Future safety gate for autonomy | **Roadmap** |

## Measurement principle

Measure user outcomes and operating confidence, not vanity metrics such as number of integrations, number of diagrams, or number of AI-generated recommendations.
